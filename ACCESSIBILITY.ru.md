# Доступность

[English](ACCESSIBILITY.md) | **Русский**

yumeclient — библиотека для Python, своего интерфейса у неё нет. Доступность здесь — это
документация и сообщения, которые выдаёт библиотека.

- Документация написана в Markdown: она читается на GitHub, на PyPI и в любом текстовом
  редакторе. Страницы размечены заголовками, у таблиц есть строка заголовков, код — в блоках
  кода, а не на картинках.
- Единственные картинки — значки в начале README, у каждого есть текстовая замена.
- Каждая страница документации есть на английском и русском, под заголовком — ссылка на
  перевод. Тексты лицензий (`LICENSE`, `THIRD_PARTY_NOTICES.md`) — только на английском.
- Ошибки — исключения и предупреждения Python с текстовыми сообщениями, поэтому экранный
  диктор или лог показывают сообщение целиком.

Известные ограничения:

- Документация есть только на английском и русском.
- Сообщения исключений и предупреждений — только на английском.

Если документацией или библиотекой трудно пользоваться с ассистивными технологиями,
[откройте issue](https://github.com/october2823/yumeclient/issues/new/choose).
